Интеграл

‹ Математикалық анализ

1. Анықталмаған интеграл

Егер F′(x) = f(x) болса, F(x) функциясы f(x)-тің алғашқы функциясы деп аталады. Барлық алғашқы функциялар жиыны анықталмаған интеграл болады, C кез келген тұрақты.

∫ f(x) dx = F(x) + C ∫ xⁿ dx = xⁿ⁺¹ / (n + 1) + C (n ≠ −1) ∫ 1/x dx = ln|x| + C ∫ eˣ dx = eˣ + C ∫ sin x dx = −cos x + C ∫ cos x dx = sin x + C

2. Интегралдау әдістері

Алмастыру әдісі: t = g(x) деп белгілеп, интегралды жеңілдетеміз.

∫ f(g(x)) · g′(x) dx = ∫ f(t) dt

Мысал: ∫ 2x · cos(x²) dx интегралында t = x², dt = 2x dx деп алсақ, ∫ cos t dt = sin t + C = sin(x²) + C.

Бөліктеп интегралдау:

∫ u dv = u · v − ∫ v du

Мысал: ∫ x · eˣ dx интегралында u = x, dv = eˣ dx деп алсақ, нәтиже x · eˣ − eˣ + C болады.

3. Анықталған интеграл

Анықталған интеграл Ньютон-Лейбниц формуласымен есептеледі. f(x) ≥ 0 болғанда ол қисық сызықты трапецияның ауданына тең.

∫ₐᵇ f(x) dx = F(b) − F(a)

Мысал: ∫₀² x² dx = x³ / 3 өрнегінің 0-ден 2-ге дейінгі айырмасы = 8 / 3.
