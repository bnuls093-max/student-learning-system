# Студенттерге жеке оқу материалдарын ұсынатын интеллектуалдық жүйе

Курстық жұмыс. Пән: Бағдарламаларды өңдеудің құрал-жабдықтары.

Технологиялар: HTML, CSS, JavaScript.

Мүмкіндіктері:
- Тіркелу және кіру жүйесі (құпиясөз SHA-256 арқылы хэштеледі)
- Email форматын және құпиясөз күшін тексеру
- Жеке кабинет
- Форум үлгісіндегі жалпы бөлім
- Оқу материалдары бөлімі (Математика, Физика)
