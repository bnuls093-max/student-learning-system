Дәріс 1 Кинематика және Ньютон заңдары
Админ
💬 0 · Админ жазды 07.10.2026
Бірқалыпты қозғалыс: v = s / t. Үдеу: a = (v − v₀) / t. Бірқалыпты үдемелі қозғалыста жол s = v₀t + at² / 2. Ньютонның екінші заңы: F = m·a, яғни дененің үдеуі оған әсер ететін күшке тура, массасына кері пропорционал.
2
Дәріс 2 Жұмыс, қуат және энергия
Админ
💬 0 · Админ жазды 07.10.2026
Механикалық жұмыс: A = F·s·cos α. Қуат: N = A / t. Кинетикалық энергия: Eк = mv² / 2. Потенциалдық энергия: Eп = mgh. Тұйық жүйеде толық механикалық энергия сақталады.

Дәріс 3 Молекулалық физика және термодинамика
Админ
💬 0 · Админ жазды 07.10.2026
Идеал газдың күй теңдеуі (Менделеев-Клапейрон): pV = νRT. Термодинамиканың бірінші заңы: Q = ΔU + A, яғни жүйеге берілген жылу мөлшері ішкі энергияның өзгеруі мен жұмысқа жұмсалады.

Дәріс 4 Электростатика
Админ
💬 0 · Админ жазды 07.10.2026
Кулон заңы: F = k·q₁·q₂ / r², мұнда k ≈ 9·10⁹ Н·м²/Кл². Электр өрісінің кернеулігі: E = F / q. Бір аттас зарядтар тебіседі, әр аттас зарядтар тартылады.

Дәріс 5 Тұрақты электр тогы
Админ
💬 0 · Админ жазды 07.10.2026
Тізбек бөлігі үшін Ом заңы: I = U / R. Джоуль-Ленц заңы: Q = I²·R·t. Тізбектей жалғағанда R = R₁ + R₂, ал параллель жалғағанда 1/R = 1/R₁ + 1/R₂.

Дәріс 6 Тербелістер және толқындар
Админ
💬 0 · Админ жазды 07.10.2026
Тербеліс периоды: T = 1 / ν. Математикалық маятниктің периоды: T = 2π·√(l / g). Толқын ұзындығы: λ = v·T, мұнда v толқынның таралу жылдамдығы.
