Жеке оқу жүйесі
Жалпы бөлім Жеке кабинет Шығу

Шек

‹ Математикалық анализ

1. Тізбектің шегі

Егер кез келген ε > 0 саны үшін N нөмірі табылып, n > N болғанда |aₙ − a| < ε орындалса, a саны {aₙ} тізбегінің шегі деп аталады.

lim aₙ = a (n → ∞)

2. Функцияның шегі

Егер x нүктесі x₀-ге жақындағанда f(x) мәндері A санына жақындай берсе, A саны функцияның шегі болады. Шектердің қасиеттері (lim f = A, lim g = B болсын):

lim (f ± g) = A ± B lim (f · g) = A · B lim (f / g) = A / B (B ≠ 0)

Мысал: (x² − 4) / (x − 2) өрнегінің x → 2 кезіндегі шегін алымын жіктеп табамыз: (x − 2)(x + 2) / (x − 2) = x + 2, яғни шек 4-ке тең.

3. Тамаша шектер

1-ші: lim sin(x) / x = 1 (x → 0) 2-ші: lim (1 + 1/x)ˣ = e (x → ∞) 3-ші: lim (eˣ − 1) / x = 1 (x → 0)

4. Функцияның үзіліссіздігі

f(x) функциясы x₀ нүктесінде үзіліссіз болады, егер сол нүктедегі шегі функцияның мәніне тең болса. Үзіліссіз функциялар қосындысы, көбейтіндісі және (бөлгіш нөл болмаса) қатынасы да үзіліссіз.

lim f(x) = f(x₀) (x → x₀)
