Қатарлар

‹ Математикалық анализ

1. Сандық қатарлар

Сандық қатар дегеніміз шексіз көп мүшенің қосындысы. Дербес қосындылар Sₙ = a₁ + a₂ + ... + aₙ. Егер Sₙ тізбегі ақырлы S шегіне ұмтылса, қатар жинақты, ал бұл шек қатардың қосындысы болады.

Геометриялық қатар |q| < 1 болғанда жинақты:

a + a·q + a·q² + ... = a / (1 − q)

Мысал: 1 + 1/2 + 1/4 + 1/8 + ... қатарының қосындысы 1 / (1 − 1/2) = 2.

2. Жинақтылық белгілері

Қажетті шарт: қатар жинақты болса, оның мүшесі нөлге ұмтылады (aₙ → 0). Бұл шарт жеткілікті емес: гармоникалық қатар 1 + 1/2 + 1/3 + ... мүшесі нөлге ұмтылса да, жинақсыз.

Салыстыру белгісі: 0 ≤ aₙ ≤ bₙ болсын. Егер Σbₙ жинақты болса, Σaₙ да жинақты. Егер Σaₙ жинақсыз болса, Σbₙ да жинақсыз.

Даламбер белгісі:

L = lim aₙ₊₁ / aₙ (n → ∞) L < 1 → қатар жинақты L > 1 → қатар жинақсыз L = 1 → белгі жауап бермейді

3. Дәрежелік қатарлар және Тейлор қатары

Дәрежелік қатар түрі: c₀ + c₁x + c₂x² + ... Ол жинақты болатын x мәндерінің аралығы жинақтылық радиусымен анықталады. Функцияны қатарға жіктеу формуласы (Маклорен қатары):

f(x) = f(0) + f′(0)·x + f″(0)·x² / 2! + f‴(0)·x³ / 3! + ...

Негізгі жіктелулер:

eˣ = 1 + x + x²/2! + x³/3! + ... sin x = x − x³/3! + x⁵/5! − ... cos x = 1 − x²/2! + x⁴/4! − ...
