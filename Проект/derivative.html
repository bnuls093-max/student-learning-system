Туынды

‹ Математикалық анализ

1. Туындының анықтамасы

Функцияның өсімшесінің аргумент өсімшесіне қатынасының шегі туынды деп аталады. Геометриялық мағынасы: график нүктесіне жүргізілген жанаманың бұрыштық коэффициенті.

f′(x) = lim [f(x + Δx) − f(x)] / Δx (Δx → 0)

2. Дифференциалдау ережелері

Негізгі туындылар кестесі:

(C)′ = 0 (xⁿ)′ = n · xⁿ⁻¹ (sin x)′ = cos x (cos x)′ = −sin x (eˣ)′ = eˣ (aˣ)′ = aˣ · ln a (ln x)′ = 1 / x

Амалдар ережелері:

(u ± v)′ = u′ ± v′ (u · v)′ = u′v + uv′ (u / v)′ = (u′v − uv′) / v² (f(g(x)))′ = f′(g(x)) · g′(x) (күрделі функция)

3. Туындының қолданылуы: экстремум

Егер f′(x) > 0 болса, функция өседі, ал f′(x) < 0 болса, кемиді. Экстремум нүктесінде f′(x₀) = 0 болады, ал туынды таңбасы өзгереді: «+» таңбадан «−» таңбаға өтсе, максимум, керісінше болса, минимум.

Мысал: f(x) = x² − 4x + 3 функциясы үшін f′(x) = 2x − 4 = 0 теңдеуінен x = 2. Туынды таңбасы «−» таңбадан «+» таңбаға өтеді, демек x = 2 минимум нүктесі, ал f(2) = −1.
